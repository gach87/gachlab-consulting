# gachlab-consulting

Public landing for CI/CD & architecture consulting (Blazor WASM → GitHub Pages).

**Live:** https://gach87.github.io/gachlab-consulting/

```bash
dotnet run --project Gachlab.Consulting.Site.csproj
```

Config: `wwwroot/appsettings.json` (`Site:CalendarUrl`, `Site:Email`, social URLs).

Ops / CRM pack lives in a **private** repo (`gachlab-consulting-pack`).
